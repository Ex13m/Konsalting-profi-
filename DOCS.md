## 2. Быстрый старт

Сборка не нужна — ни npm-скриптов, ни бандлера. Достаточно любого
статического сервера:

    git clone https://github.com/Ex13m/Konsalting-profi-
    cd Konsalting-profi-
    python3 -m http.server 8080

Открыть `http://localhost:8080`. Всё, кроме серверных функций, работает
локально: страницы, переводы, календарь, голограмма, ценник.

Функции (`/api/*`) локально не поднимаются без Netlify CLI. Сайт это
переживает: запись переключается на запасной путь («отправьте письмом»),
лента новостей просто не появляется, кнопка звонка не показывается.

`package.json` нужен только для двух зависимостей серверных функций
(`@anthropic-ai/sdk`, `@netlify/blobs`) и для номера версии.

Три вида оформления переключаются одной кнопкой по кругу:
светлое → тёмное (`body.dark`) → классическое (`body.classic`).
Выбор хранится в `localStorage`. Контраст всех шести сочетаний
тема × состояние шапки выверен по WCAG.

## 5. Многоязычие

Шесть языков: чешский (исходный), английский, русский, украинский,
немецкий, польский.

**Как это работает.** Язык выбирается до отрисовки страницы — из
`localStorage['kp-lang']`. По языку браузера ничего не угадывается:
телефон, настроенный по-польски, ещё не значит, что человек читает
по-польски; вместо этого внизу ненавязчиво предлагается переключиться.

Дальше грузится один словарь (`assets/i18n-<язык>.js`, ~17 КБ) и
`TreeWalker` проходит по всем текстовым узлам, подменяя текст. Ключ
словаря — **исходный чешский текст**. Узлы внутри `.num` и `.dyn`
пропускаются: там числа, адреса, имена собственные и содержимое,
которое рисуется скриптом и переводится отдельно через `T()`.

`assets/i18n-data.js` — не словарь, а таблица: строки интерфейса
(`U('...')`), названия месяцев и дней недели сразу на всех языках.

### Добавить переведённую строку

1. Написать текст по-чешски в разметке.
2. Дописать пару «чешский → перевод» в каждый из пяти файлов
   `assets/i18n-*.js` перед закрывающей `};`.
3. Проверить переключением языка в браузере.

Строку, которую рисует скрипт, оборачивать в `T('чешский текст')`.
Строку интерфейса (кнопки, предупреждения) — добавлять в `i18n-data.js`
и звать через `U('ключ')`.

### Добавить язык целиком

Прибавить код в массив `L` в начале `index.html`, в список `LANGS`
переключателя, в `EU_LANG` внутри `news.mjs`, завести
`assets/i18n-<код>.js` и колонку во всех записях `i18n-data.js`.

## 6. Запись на приём

Самая связанная часть проекта: правила заданы в одном месте на клиенте,
и те же правила проверяются на сервере.

### Правила приёма

| День | Что показывает сайт |
|---|---|
| Понедельник, среда | приёмные дни: весь рабочий день по часам, свободны только блоки **10–11** и **11–12**, остальные перечёркнуты |
| Вторник, четверг | обычный режим работы 10:00–18:00 (перерыв 13:00–14:00), вместо часов — кнопка «Позвонить» |
| Пятница | приёма нет |
| Суббота, воскресенье | в календаре не показываются |

Консультация — 45 минут, бесплатная. Показываются восемь ближайших
будних дней.

Константы в `index.html`, раздел `ОБЪЕДНАНИЕ ТЕРМИНУ`:

```js
const HODINY = [[10,13],[14,18]];  // рабочий день по часовым блокам
const DEN_SCHUZKY = [1,3];         // приёмные дни (пн, ср)
const DEN_TELEFON = [2,4];         // обычный режим (вт, чт)
const VOLNE = ['10:00','11:00'];   // блоки, открытые для записи через сайт
```

### Что происходит при отправке

1. Браузер шлёт `POST /api/objednat`.
2. Функция **заново** проверяет: день приёмный, время из списка, дата
   в будущем и не дальше 60 дней, имя от двух символов, телефон от
   девяти цифр, почта по формату.
3. Проверяет, что блок ещё свободен, и пишет запись в Netlify Blobs.
   Ключ хранилища — сам слот (`slot/2026-09-16T10:00`), поэтому двойная
   бронь невозможна физически.
4. Отправляет письмо в контору и подтверждение клиенту — оба
   с приглашением `.ics`. Подтверждение на языке, который человек
   выбрал на сайте.
5. Отвечает `{ok:true, id, mail}`.

**Если что-то пошло не так**, сайт не ломается:

- `409` — блок заняли, пока человек заполнял форму: показывается
  сообщение, календарь обновляется, форма остаётся заполненной;
- сеть или функция недоступны — показывается термин, предлагается
  скачать `.ics` и отправить письмом, и честно говорится, что
  автоматически отправить не вышло.

### Занятость

`GET /api/objednat` отдаёт только занятые времена — `{"obsazeno":[…]}`,
никаких персональных данных. Сайт по ним гасит блоки при загрузке.

### Защита от роботов

- скрытое поле `#b-web`, которого человек не видит;
- заполнение быстрее трёх секунд считается роботом;
- не больше трёх записей с одного адреса в сутки;
- роботу отвечаем «всё в порядке», чтобы не пробовал снова.

### Хранение

Netlify Blobs, хранилище `objednavky`. Записи старше года функция
удаляет сама — это тот же срок, что записан в политике обработки данных.

## 7. Ассистентка, звонок, голограмма

### Чат-ассистентка

Плавающая кнопка внизу справа. Работает **без сервера**: в странице
лежит база знаний из двух десятков тем (сроки, цены, мзды, переход от
другой бухгалтерии, адрес, режим работы…). Вопрос сопоставляется
с ключевыми словами на шести языках.

Если задана `ANTHROPIC_API_KEY`, страница шлёт вопрос на
`/api/assistant`, и отвечает уже модель — с теми же фактами
в системном промпте. База знаний остаётся запасным путём.

Расход на API посчитан в `docs/API-naklady.md`.

### Голосовой звонок

Третья плавающая кнопка. Появляется **только** если задана
`LIVE_ENABLED=1` — без этого сайт выглядит как раньше, так что
выкладывать безопасно даже до настройки.

`netlify/functions/live-session.mjs` выдаёт браузеру короткоживущий
токен; постоянный ключ сервер не покидает. Дальше браузер соединяется
с моделью напрямую по WebRTC. Разговор жёстко ограничен восемью
минутами, за минуту до конца Клара предупреждает.

Подробности и незакрытые вопросы — `docs/hlasovy-hovor.md`.

### Голограмма

Проекция запускается только кнопкой проектора, сама не появляется.
Под Кларой показываются три кнопки: записаться, скачать ценник,
перезвонить.

`assets/klara-zive.js` рисует её на canvas из одной прозрачной
фотографии, разрезая на три горизонтальные полосы: над носом без
изменений, лицо от носа до подбородка растягивается по громкости,
шея сжимается на ту же величину. Между губами вырезается дыра —
открытый рот получается просветом, а не тёмным пятном.

Кроме рта есть «язык тела»: мерцание на слоге, кивок в конце фразы,
дыхание, полоса обновления. Громкость берётся из `AnalyserNode`,
поэтому всё это не зависит от того, кто отдаёт звук.

Координаты лица заданы долями изображения в объекте `TVAR` — при замене
фотографии правится только он.

Есть вход для внешнего аватара: `KPHolo.obraz(mediaStream)` покажет
готовый видеопоток вместо рисования, фон срежется тем же фильтром.

## 8. Ценник

`cenik.html` — отдельная страница, 21 позиция в пяти группах, цены без
НДС, помечены как ориентировочные: итог всё равно складывается после
встречи.

Язык берётся из `?lang=` в адресе или из `localStorage`, словарь тот же,
что у сайта. Числа, адрес и название конторы помечены классом `num` и
не переводятся.

PDF — по одному на язык, генерируются из **той же** страницы, чтобы
цифры не разошлись:

    python3 -m http.server 8899 &
    PLAYWRIGHT_DIR=<путь к node_modules> node tools/cenik-pdf.mjs

**После любой правки цен PDF надо перегенерировать.**

Ссылки на ценник: подвал, ответ в разделе «Вопросы», кнопка под Кларой,
ответ ассистентки. Ведут в той же вкладке, поэтому «назад» возвращает
человека ровно туда, где он был.

## 9. Экономическая лента

`netlify/functions/news.mjs` собирает публичные RSS: Чешский нацбанк,
Финансовая администрация, Минфин ЧР и Еврокомиссия. Заголовки не
выдумываются — пересылается то, что издают сами источники.

При заданной `ANTHROPIC_API_KEY` к ним добавляется перевод на пять
языков и одна фраза «о чём это для предпринимателя». Переводы
складываются в Blobs (`news-i18n`), чтобы не платить дважды за один
и тот же заголовок. Без ключа лента показывает чешские оригиналы.

## 10. Переменные окружения

Задаются в Netlify → Site configuration → Environment variables.
**Сейчас не задана ни одна** — всё, что от них зависит, выключено.

| Переменная | Для чего | Без неё |
|---|---|---|
| `ANTHROPIC_API_KEY` | ответы ассистентки, перевод ленты | работает база знаний, лента по-чешски |
| `ASSISTANT_MODEL` | модель ассистентки | `claude-opus-5` |
| `NEWS_TRANSLATE`, `NEWS_MODEL` | перевод заголовков | по умолчанию |
| `RESEND_API_KEY` | письма о записи | запись сохраняется, писем нет |
| `RESEND_FROM` | отправитель писем | `onboarding@resend.dev` |
| `OBJEDNANI_MAIL` | куда приходят заявки | `konsaltingprofi@gmail.com` |
| `OPENAI_API_KEY` | голосовой звонок | кнопки звонка нет |
| `LIVE_ENABLED` | `1` показывает кнопку звонка | кнопки нет |
| `LIVE_MODEL`, `LIVE_VOICE`, `LIVE_BACKEND_MODEL` | настройка звонка | по умолчанию |

Ключи в коде и в git не хранятся никогда.

## 11. Версии и деплой

Номер версии живёт в `package.json` и оттуда штампуется в страницы —
в `<meta name="kp-verze">` и в подвал. По нему видно прямо с открытого
сайта, доехал ли деплой.

    node tools/verze.mjs           показать текущую
    node tools/verze.mjs 1.1.0     переписать везде и завести раздел в CHANGELOG

Нумерация semver: **мажор** — переделка, после которой сайт смотрят
целиком; **минор** — новый раздел или функция; **патч** — тексты, вёрстка,
переводы.

Что менялось — в `CHANGELOG.md`, там же таблица «версия → коммит»,
чтобы сравнивать:

    git log --oneline d86e0c2..8609e79
    git diff d86e0c2..8609e79 -- index.html

Те же точки помечены тегами `v0.1.0`…`v1.0.0`. Теги лежат локально —
среда, в которой они ставились, не пропускает их push. Уходят обычным
`git push --tags`.

## 13. Правовое

`ochrana-osobnich-udaju.html` — полный текст политики: кто контролёр,
что собирается, на каком основании, кому передаётся, сколько хранится,
права человека. Сроки в тексте и сроки в коде совпадают: незакрытая
заявка — не дольше 12 месяцев, и ровно столько же живёт запись
в хранилище.

**Текст писался без юриста.** Перед публикацией на основном домене его
стоит вычитать. Отдельно: когда подключатся Resend и модели, их нужно
будет назвать в списке обработчиков (ст. 28 GDPR).

## 14. Что не доделано

1. **Домен.** `konsalting.cz` отдаёт старый сайт. Новый живёт только на
   netlify-адресе.
2. **Почта.** Без `RESEND_API_KEY` запись сохраняется, но о ней никто не
   узнаёт. **До переезда на домен это обязательно закрыть** — иначе форма
   станет чёрной дырой: клиент выберет время, а в конторе не увидят.
3. **Заявки негде посмотреть.** Записи лежат в Blobs, интерфейса к ним
   нет. Пока идёт тест — это слепая зона.
4. **Календарь конторы** не подключён: занятость берётся из записей на
   сайте, а не из реального календаря. Место под это готово — функция
   `window.KP_OBSAZENO(дата, начало)`.
5. **Голосовая Клара.** Нужен Agent ID из ElevenLabs и ответ, публичный
   агент или с авторизацией. Всё остальное на сайте готово.
6. **Формы `#leadform` и `#exitform`** (обратный звонок и выход) никуда
   не отправляются — в отличие от формы записи.
7. **Публикуется весь репозиторий.** В `netlify.toml` стоит
   `publish = "."`, поэтому наружу отдаются и `tools/`, и `brand/`,
   и `package.json`, и исходники прототипа в `prototypes/`. Секретов
   там нет, но внутренняя кухня видна. Лечится переносом сайта
   в отдельную папку или списком исключений.
8. **Видео в шапке** — необязательное: положить `assets/hero.mp4`,
   и оно появится само. Без файла ничего не ломается.

## 15. Частые задачи

**Поменять цену.** `cenik.html` → перегенерировать PDF
(`node tools/cenik-pdf.mjs`) → закоммитить оба.

**Поменять телефон или адрес.** Искать по строке в `index.html`,
`cenik.html`, `ochrana-osobnich-udaju.html`, `netlify/functions/*.mjs`
и `docs/eleven-agent.md` — телефон встречается и в промптах.

**Поменять приёмные дни или часы.** Константы `DEN_SCHUZKY`,
`DEN_TELEFON`, `VOLNE` в `index.html` — и **те же правила** в
`netlify/functions/objednat.mjs` (`DNY_SCHUZEK`, `BLOKY`). Разойдутся —
сайт будет предлагать время, которое сервер отвергнет.

**Добавить вопрос в FAQ.** Блок `#faqbox` в `index.html`, дальше
перевести строку в пяти словарях.

**Заменить фотографию Клары.** Положить новую `assets/klara.webp`
с прозрачным фоном и подправить доли лица в `TVAR`
(`assets/klara-zive.js`).

**Выпустить версию.** `node tools/verze.mjs 1.1.0` → описать изменения
в `CHANGELOG.md` → коммит → тег → push.

## 16. Если что-то сломалось

**Сайт отдаёт старое.** Посмотреть версию в подвале и в исходнике
(`kp-verze`). Если старая — деплой не доехал: Netlify → Deploys.

**Запись не сохраняется.** `GET /api/objednat` должен отвечать
`{"obsazeno":[…]}`. Если 404 — функции не собрались; если 500 —
смотреть Netlify → Functions → `objednat`.

**Ассистентка отвечает не на том языке.** Язык передаётся отдельным
блоком после точки кэширования и дублируется в тексте запроса —
проверять в `netlify/functions/assistant.mjs`.

**Сайт перестал открываться целиком.** У Netlify кончились кредиты:
на бесплатном плане 300 в месяц, автопополнения нет. Стоит включить
уведомление об исчерпании.

**Голограмма не запускается.** Локально в Chromium без H.264 не
проигрывается `klara-uvitani.mp4` — это особенность окружения, а не
сайта; на боевом всё в порядке.
